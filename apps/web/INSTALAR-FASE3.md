# Fase 3 · rutas (Windows, PowerShell)
1. Descomprime este zip SOBRE C:\APPS\ecoroute (acepta reemplazar). No hay migración nueva ni paquetes nuevos.
2. Si la web está corriendo, detén con Ctrl+C y ejecuta: npm run dev  (desde apps\web)
3. Como admin: Rutas > Nueva ruta. Antes necesitas 1 camión, 1 conductor y varios contenedores (Fase 2).
Opcional: OSRM_URL=https://tu-servidor en .env.local para usar tu propio servidor de rutas.
Tiempo estimado = conducción + 60 s por contenedor.
